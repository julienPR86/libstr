# My simple string library

## Description

This is a simple string library that i use in my personal projects.

## Instructions

To use this lib, you can add the header in the necessary files, and add `#define LIBSTR_IMPLEMENTATION` in **only one** of them to get access to the function definitions.

It should look something like:
```
#define LIBSTR_IMPLEMENTATION
#include "libstr.h"
```
